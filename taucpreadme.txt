1. Brief Introduction
---------------------

Total Annihilation Units Compilation Pack is a unit pack that contains over 230 3rd 
Party Units from various unit groups that have been thoroughly checked to ensure the 
quality of these units. The units that are in TAUCP have been revised and refined to
ensure that the game is still balanced while maintaining the fun factor of the game. 
Here are some of the features of TAUCP at this moment :

- Contains Over 230 3rd Party Units from various unit groups.
- Conflict free and 99% bug free gameplay (nothing is 100% bug free)
- Incorporates Switeck's TA Bugfix Version 1.6
- More Balanced Gameplay with 3rd Party Units
- Includes a Frontend Utility to enable/disable TAUCP, to select the AI to play against,
  to set the starting metal & energy (can be more than 10000 metal/energy!) and to
  select which unit pack sections (land, sea, air, etc) that you want to play with !
- Includes a user friendly Installer to ensure smooth installation of the Unit Pack
- Incorporates Switeck's Mostly Harmless AI Version 13 (don't let the name fool you!) 
  and Banzai 3.0 by M. Kenyon
- Total Annihilation Units Compilation Pack is based on Total Annihilation 
  Units Independancy Pack Version 2.1 created by CyberKewl (that's me!)

4. The TAUCP Frontend (NON-TAM Version only)
--------------------------------------------

One of TAUCP's unique features is that it includes a frontend. With this frontend, you can set your Starting Metal & Energy resources that can exceed 10000 metal and energy (for skirmish only), enable/disable the unit pack, select the AI to play with or visit TAUCP Central. Besides that, you are now able to select which section that you want to enable or disable such as air units, ground units, hovercrafts, sea units and structures. Note: this only affects all the units in TAUCP, it does not affect other units such as standard cavedog units (meaning that you can't disable cavedog-specific sea units and so on).

To enable/disable unit pack sections, launch the TAUCP frontend and click on the "unit pack options" button followed by the "Enable/Disable unit pack sections" button. Then select the unit pack section(s) that you want to enable/disable and press the accept changes button.

Tip: To display which sections are currently enabled quickly, double click anywhere on the frontend's main background.

Notice: When playing TAUCP in a multiplayer environment, please ensure that all sides have the same EXACT unit pack sections enabled or else there 
may be problems (such as greyed out units, etc)

There are different levels of AI's : Easy Boost, Standard Boost, Hard Boost and Standard Version (Only for Mostly Harmless AI)

Easy Boost
----------

The easy boost AI cheats on a smaller scale, but can give you a good fight. This AI does NOT 
build nuclear silos.

Standard Boost
--------------

The standard boost cheats at a decent rate and will give you a good run for your money. This
AI will build nuclear silos as well so prepare those anti-nukes ! Not only that, they have
access to improved versions of the Arm High Tech Lab and Core Krogoth Gantry to speed up unit
production in those level 3 factories.

Hard Boost
----------

The ultimate boost, the Hard Boost cheats a lot and will make you suffer especially on maps
where metal are scarce. This AI will build nuclear silos just like the standard boost BUT it
can launch the nuclear much faster, so beware ! Not only that, they have access to improved
versions of the Arm High Tech Lab and Core Krogoth Gantry just like the standard boost, but
they can produce units (in the factory) at a much faster rate. If you can beat at least 3 of
the Hard Boost AIs allied together, you're pretty good !

Standard Version (Mostly Harmless AI Only)
------------------------------------------

With the standard version of Mostly Harmless AI, you will be up against a fair AI - 
this AI doesn't cheat at all, so they won't be that challenging to hardcore TA players.
Besides that, this AI does NOT use nukes unlike the boosted versions (Standard & Hard).

Here is a step by step guide on how to play TAUCP with TA:M :

1) Run TA Mutation.
2) Disable ALL existing TCs, AIs, etc
3) Enable/Select the TAUCP TC in the Total Conversions menu
4) Enable/Select only ONE of the many available AI Boosts from the Mutators menu
5) Enable/Select either the Mostly Harmless AI or the Banzai AI from the AIs menu

enable the Mostly Harmless AI Standard Boost with the Banzai AI (in the AIs menu).
TAUCP will still work but you will get a dummy AI - one that does NOT do anything.

you have selected. In other words, you can ONLY ENABLE ONE of the many available AI
boosts from the Mutators menu. To deselect the selected Mutator from the Mutators
menu, just click on the selected mutator(s) again. Only one ai boost/mutator
should be enabled/selected at any given time.

Example :

Select the TAUCP TC in the Total Conversions menu. Then, select the Mostly Harmless
AI Standard Boost from the Mutators menu. Next, Select the Mostly Harmless AI from
the AIs menu. Finally, select taucp2-airunits, taucp2-structures then Launch TA and have fun.

7. More Units In TA
-------------------

Instead of the default 200/250 max units, you can have up to 500 units by creating a
file named totala.ini in your TA folder. Copy and paste the contents below into a new
file - minus the "begin" and "end" lines :

---BEGIN---
[Preferences]

; Specifies the maximum number of units per player.  Default is 200.
; Warning:  The higher the number, the more resources are required.
; If the game slows down with higher numbers, you will need
; more RAM and/or a faster CPU.

UnitLimit = 500;


; Disable the use of DirectSound.  Set this to 1 to disable
; sound in the game.  Set it to 0 to use sound normally.
;
; Disable the sound if you do not have a sound card or
; the game crashes while trying to play sounds.

NoDirectSound = 0;


; Use the standard Windows multimedia interface for playing sounds
; instead of DirectSound.  Set this to 1 to use Windows sound, and
; 0 to use DirectSound.
;
; Note:  Setting this value to 1 will allow you to play the
; game if DirectSound does not work properly on your system.
; However, the audio quality will be greatly decreased,
; especially during heavy battles.  Also, you will not get any
; audio narration with your mission briefings or any sound in the
; movies.

UseWindowsSound = 0;
---END---

You can change Unitlimit = 500 to something smaller if desired.


10 Players In Skirmish
----------------------

To get up to 10 players in a skirmish game, do this :

When in the skirmish room, type asterisk (shift+8), after that type the roman 
numeral number of the amount of players you want. 

For example, if you want 10 players in skirmish mode, you'd type "x", and for five players you'd type "v". 

1 = i ; 2 = ii ; 3 = iii ; 4 = iv ; 5 = v ; 6 = vi ; 7 = vii ; 8 = viii ; 9 = ix ; 
10 = x. 

NOTICE : On Windows NT, 2000 and XP Operating Systems, you need to be an Administrator
         in order for the TAUCP frontend to function properly.
