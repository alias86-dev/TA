TOTAL ANNIHILATION READ ME
DOWNLOADABLE UNIT - ARM FLEA

ARM Flea - UNIT DESCRIPTION
For 44 metal and 712 energy, the ARM Kbot Lab can build 
the Flea.  The flea is a very small, agile, lightly armored 
Kbot scout.
 

INSTALLING THE NEW UNIT
After downloading the new unit, double-click to extract
the unit file.  The unit file (unitname.UFO) will be
placed in the c:\cavedog\Totala folder unless otherwise 
specified.  The unit file must be located in the same 
directory as Totala.exe.  After the unit is installed, 
it will appear on the appropriate build menus the next time 
the game is launched.

**You must have Total Annihilation version 1.2 BETA 1 or 
greater in order to use a downloaded unit.  You can download
the most recent patch for Total Annihilation from 
www.totalannihilation.com.**

USING THE NEW UNIT
After having installed v1.2 BETA 1 or greater as well as the 
new unit file, the downloaded unit will be available on the 
build menus in Skirmish and Multiplayer mode.  The new unit 
will not be available while playing missions.

When using the new unit in a multi-player game, all players
must have the downloaded unit installed.  If one player
does not have the new unit available to them, none of the 
players will be able to use the new unit for that 
multi-player game.
